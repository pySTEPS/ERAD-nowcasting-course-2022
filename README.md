# OpenSense 2025 Training School session: OS-based nowcasting with pysteps

The main goal of this course is to focus on practical aspects of nowcasting, while using conventional and less conventional (opportunistic) gridded rainfall data. The course will combine theory with hands-on sessions based on the open-source library pysteps, while offering an opportunity to gather the nowcasting community around pysteps to discuss challenges and future developments.

**When:** 1 - 4 April, 2025 (specific session on Wednesday 2 April afternoon)
